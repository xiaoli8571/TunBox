# 永久 GitHub 推送规则

提交和推送前必须阅读 [GITHUB_PUSH_BOUNDARY.md](docs/GITHUB_PUSH_BOUNDARY.md)。

禁止推送任何敏感数据、任何脚本、任何签名文件及安装包。唯一例外是用户明确要求发布特定版本时，通过本地上传闸门上传一个已验证未签名且版本匹配的 HAP 到对应 Release。必须检查整个待推送历史；含禁止内容的本地提交不得作为新推送的祖先。代码只允许审核后的源码、必要非敏感配置和规则文档。禁止整体暂存；不自动发布 Release；保留本地工作区和 Windows 子仓库。

此规则是用户于 2026-11-13 的明确指令，优先于旧推送技能的白名单。
