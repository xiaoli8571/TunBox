## 本版改动

### 1. 冷启动 ANR 修复（本版最重要）

0.7.9 把 geo 资源改成包内 `.gz` 后，首次启动要在**主线程**用纯 TS inflate 解压
`geoip.metadb`（9.6MB）+ `geosite.dat`（4.4MB），实测 19:21:06.942 → 19:21:11.117
（差 4.17s），主线程累计约 16s 无响应，系统弹出「TunBox 没有响应」。

- 改为 **原生 zlib 流式解压**（`@ohos.zlib` GZip，API 12+）：包内 `.gz` 先落成
  staging 临时文件 → `gzopen` → 1MB 分块 `gzread` → `gzclose`，全程不进 JS 堆。
- 真机实测 2026-10-31：`gzopen+gzfread` 报 `17800009 Internal structure error`
  （36ms 内两侧同时失败，非慢非脏数据）；现按 `gzopen/gzdopen` ×
  `gzread/gzfread` **4 种组合逐条试**，全部失败原因单独打 hilog，
  当前真机走通 `gzopen+gzread`，两个资源各在 **毫秒级**完成。
- `gzfread` 返回**负数必须当错**（只有 0 才是 EOF）：否则 CRC32 不匹配的截断流
  会被静默接受，而 geosite 的头部探测照样能通过，坏文件就成了好文件。
- 结构校验保持**有界探测**：整体完整性交给 gzip CRC32/ISIZE，MMDB 只读尾 4KB、
  GeoSite 只读头 256KB；整文件模式截断即坏。落盘契约（文件名、校验方式、
  原子替换）未变，失败一律保留原文件等下轮重试。

### 2. 内核裁剪

- 编译期裁掉 `no_tailscale,no_zerotier,no_easytier`，`libgojni.so`
  62.96MB → 43.62MB（sha256 与 `libgojni.sha256` 匹配）。

### 3. Geo 资源压缩

- rawfile 改存 `.gz`：13.43MB → 5.72MB（-57.4%）；包内 STORED 不二次压缩
  （`geoip.metadb.gz` 4,685,418 B / `geosite.dat.gz` 1,309,517 B）。

### 4. 沉浸式 Dock / 安全区 / 滚动渐隐

- 底部 Dock 走沉浸式，`SafeArea` 统一收口，滚动容器使用 `fadingEdge` 边缘渐隐，顶栏保留连续淡染色；不使用曾导致真机闪烁/空白的 `linearGradientBlur`。
- 本轮修复顶部 inset 单独变化不通知页面重排的问题；真实 SafeArea 源码回归通过。Dock 门禁 43/43，负向自检 5/5。

### 5. 后台保活与通知

- 保活策略：`dataTransfer` 优先，被拒回退 `taskKeeping`；guard 无答复记为
  `LatencyState.TIMEOUT`，不再把「没回答」当成功。

### 6. 订阅区重构（SubscriptionSection）

- 单订阅测速防重入：`testingIds` + `finally` + `latencyRevision` 递增；
  测速结果区分 `null` 与真实成功，`null` 显示「测速未执行，请稍后重试」。
- `refreshAll()` 保持**串行**快照语义；并发只发生在 `NodeSelectionPage.refreshNodes()`。
- 订阅增删改不自动重连，节点切换即时重连。
