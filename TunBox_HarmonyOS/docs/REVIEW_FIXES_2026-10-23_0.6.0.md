# TunBox HarmonyOS 0.6.0 修复与交付

日期：2026-10-23。最终 versionName=0.6.0，versionCode=525。

## 修复

- 内核新增离线 profile 校验/规范化入口：完整 YAML 文档展开锚点；协议、组引用、重复名及无需 Geo 数据的规则语法交给同一内核解析器校验；不启动内核或下载 provider。坏订阅不替换旧 profile。
- Base64 YAML 先解码再校验；裸节点的流式、单引号、转义名称都能生成有效分组。规范化前的原始响应仍由原文存储保存。
- profile 内容版本和节点详细参数纳入新鲜度判定；同订阅密码、TLS、规则等变更可触发重载。
- 原文接管 outbounds 时，运行参数 overlay 不依赖 App 侧节点表；provider/内核协议可先加载再读目录，本地导入不再因旧解析器零结果被拦。
- 组选点沿可选择的嵌套组链设置，并读回确认；失败不再进入 CONNECTED。
- 测速完成、取消、守护到期按批次清理 TESTING，保留已有结论；旧批不覆盖新批标记。
- native stopCore 改为异步 worker，避免等待 Go 生命周期互斥锁时阻塞 ArkTS 事件循环。
- 用户实测补修：通道未开始或没有任何测速结论时不报“测速完成”。手动测速在旧会话不新鲜、控制器无响应、复查租约与会话代次均安全时可重建 headless 核；页面自动预热继续保留保护。
