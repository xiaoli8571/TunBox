## 验证方式

- `verify-latency-scope-runtime.mjs`：执行生产 ArkTS，替换鸿蒙平台边界；20 项运行回归覆盖跨 profile/内容/URL/期望码隔离、持久化恢复、键长与身份检查、组策略继承、组行读取、取消、真实 504、无响应保留、热切回读、重连回退与晚到断开、独立上下文和旧页面按订阅分批/同名排序。
- `verify-headless-socket-bind.mjs`：执行生产 Go 的 socket 钩子和 protect 判定代码，只替换管道 I/O 与日志边界；验证物理绑定失败拒绝拨号，且不能绕过 VPN protect 正回执。
- 原 provider 路由/目录真实 loopback 内核回归、面板运行回归、旧测速引擎兼容回归继续保留。未以主机 loopback 延迟推断用户机场延迟。
- `verify-arkts-compile.mjs` 改为 `clean assembleHap --no-daemon`，成功后立即校验 UI 资源绑定；总门禁不再通过增量打包绕过仓库构建约束。
- ARM64 Go 内核已交叉编译，新库已包含 `TunBoxSetSocketBinder` 导出。系统绑定 API、NAPI、ArkTS 的真实构建是编译验收；手机上的绑定结果仍需下列装机验收。
