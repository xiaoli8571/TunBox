## 修复

**网站分流 / 应用分流显示问题**
- 网站分流「添加 / 批量导入网站」的提交按钮改为品牌蓝底白字，并按域名合法性实时启用；输入即回显「已识别 N 个域名」，不合法行就地标红。原先 `primaryBlueFill`（浅色填充）配白字，看起来永远是灰色。
- 网站分流顶部三态标签的数量改为按 kind 现算（`countOf`）：`@Builder` 的**按值参数**不会随 `@State` 刷新，之前添加后标签一直停在 0，现在「强制直连 1」会立即出现。
- 节点页批量多选圆点改为按节点 id 现查状态（`SelectDot(nodeId)`），点一行即变色。
- 节点状态徽标（连续失败 / 成功率）把状态签名并进 `ForEach` key，状态更新后行会重建，不再停在首次渲染的值。

**备份 / 恢复（卸载重装后导入备份选不了节点、刷新不出来、启动代理失败）**
- 备份升级到 **2.1**：新增 `profiles[]`（每份订阅的配置原文，内核真正的节点来源，含节点密码）、`subscriptionSecrets[]`（Asset 里的订阅 header 值）、`currentProfileId`。
- 恢复时写回 `profiles/<id>.yaml`、切回 current profile、把订阅 header 值补进 Asset；旧版备份（无 `profiles`）同样可用。
- 恢复后对所有启用订阅**按订阅链接串行后台重拉一次**：节点、流量、到期信息保持最新；单条失败只记日志，不影响已恢复的离线可用配置。
- 恢复 settings 时**不再用备份里的 `proxyMode` 覆盖本机**：之前备份若是在全局模式导出的，重装导入后会直接变成全局模式；现在保持本机当前模式（全新安装默认仍是规则模式）。
