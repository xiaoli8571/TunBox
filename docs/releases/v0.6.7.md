## 新增

- **应用分流 · 批量删除**：列表过滤行新增「批量删除 / 完成」入口，批量勾选（或全选当前结果）后一次确认即可从「仅代理名单 / 绕过名单 / 手动目录」中移除所选条目；预置条目记入已删除名单，保存后不再出现。仍是草稿语义，点「保存」才生效，任何分流模式（含全部代理）都能用。
- **导入支持「名称|包名」**：添加 / 导入弹窗每行可写 `支付宝|com.alipay.mobile.client`（半角 `|`、全角 `｜`、制表符均可，`包名|名称` 也能识别，只写包名仍然可行）；输入即回显「已识别 N 项：名称 · 包名」，不合法行就地提示。名称备注输入框保留，仅对单条输入作为默认名称。

## 改进

- 测速链路重做：节点延迟请求改走本地内核 controller 的 TCP 通道并加通道预热，80 节点批次 30.1s → 3.66s；单节点超时 3s、在途并发 32（上限 64）。
- 全局模式下 GLOBAL 组钉选修复；节点页长列表滚动掉帧优化。

## 修复

- 添加应用弹窗「添加到当前名单」一直是灰色、输入包名也不高亮：按钮底色误用浅色填充 `Ui.primaryBlueFill` 配白字，已改为品牌蓝底白字并按输入合法性实时启用（`AppRoutingPolicy.entriesError`）。
- 批量勾选复用 Checkbox 时，进入批量模式那一帧整表 `checked` 变化被当成用户点击（会预先勾上全部条目），已加模型对齐守卫：`if (checked !== model.includes(key)) { toggle(key); }`。
